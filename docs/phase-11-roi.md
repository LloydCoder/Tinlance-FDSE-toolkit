# Phase 11 — ROI and Business-Impact Analysis

The historical ROI model was audited and found to combine external breach benchmarks, hard-coded incident frequencies, regulatory penalty assumptions, and ThreatFade detection latency into a single causal ROI claim. That is not defensible without customer-specific validation.

The maintained model therefore requires an explicit customer/engagement baseline annual loss and an explicit risk-reduction assumption. It calculates expected loss avoided, ROI multiple, payback, and sensitivity at 10%, 25%, and 50% risk reduction.

IBM's 2025 Cost of a Data Breach research is retained as an informational benchmark source, not silently substituted for customer loss assumptions. The model explicitly states that detection latency is not itself a dollar-value causal model.
