# Phase 22 — Cross-Platform Compatibility

The maintained Python Toolkit is now tested on the GitHub-hosted latest Linux, Windows and macOS runners across Python 3.11–3.14.

This is source-package compatibility evidence only. It does not certify the historical Linux binaries, Tkinter GUI, PyInstaller output or a particular air-gap workstation. Those require artifact-specific clean-environment evidence.

The field operator should use the compatibility workflow as the minimum regression matrix before claiming source-package portability to a customer environment.
