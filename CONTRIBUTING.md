# Contributing

This is a private Tinlance engineering repository. Changes follow serial phase discipline.

1. Audit the current implementation.
2. Research current authoritative standards and dependency/security advisories.
3. Define acceptance criteria.
4. Implement the smallest complete change.
5. Add or update automated tests.
6. Update documentation and claims.
7. Run local validation and CI.
8. Merge only when required checks are green.
9. Re-audit the merged result before starting the next phase.

Do not execute scanners against real customer targets without explicit authorization and a documented scope.
