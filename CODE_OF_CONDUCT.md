# Code of Conduct

## Our standard

We expect contributors and maintainers to communicate professionally, respectfully and in good faith.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, deliberate disruption, doxxing, publishing private information, or attempting to expose customer/security data.

## Security-sensitive behavior

Never publish customer evidence, credentials, private keys, personal data or vulnerability details that could materially increase risk.

Security reports belong in the private process described in [SECURITY.md](SECURITY.md).

## Enforcement

The repository maintainer may remove comments, close discussions or restrict participation when behavior violates this code or threatens the security of the project or its users.

## Scope

This code applies to repository issues, pull requests, discussions, reviews and other project collaboration spaces.

For concerns about conduct, contact the repository maintainer privately through GitHub.
