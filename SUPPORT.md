# Support

## Repository and usage questions

For questions about installation, CLI usage, documentation or maintained behavior:

1. Check the [README](README.md).
2. Check the [repository map](docs/repository-map.md).
3. Check the [field pilot runbook](docs/field-pilot-runbook.md).
4. Search existing GitHub issues.
5. Open a new issue only when the answer is not already documented.

Do not include customer evidence, secrets, credentials or sensitive security details in public issues.

## Security issues

Do not use public issues for vulnerabilities or sensitive security reports. Follow [SECURITY.md](SECURITY.md).

## Field engagements

The Toolkit does not grant authorization to test infrastructure. Engagement questions must be handled through the applicable Tinlance customer engagement and scope process.

## Commercial or licensing questions

This repository is proprietary. Contact Tinlance Limited through [tinlance.com](https://tinlance.com/) for commercial licensing or permission questions.
